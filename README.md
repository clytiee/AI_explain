# 划词AI释义（AI_explain）

一个浏览器扩展（Chrome / Edge，Manifest V3）：**选中网页上的文本 → 自动弹出浮层 → 调用你配置的大模型 API → 对所选文本进行释义、翻译或讲解**。风格类似「划词翻译」，但由 AI 自由解释，而非仅翻译。

## 功能

- 选中文本后自动弹出毛玻璃浮层，默认自动调用 AI 解释（也可改为手动点「解释」）。
- 释义采用**流式输出**（逐字显示）；支持复制释义、一键跳转设置。
- 发送时带上选中文本所在的**页面上下文**（前后各一段文字），让 AI 更准确理解语境。
- 滚动页面时浮层跟随选中区域重定位。
- 内置 DeepSeek / 豆包(火山方舟) / OpenAI / Kimi 常用配置，也支持任意 OpenAI 兼容接口。
- 右键菜单提供「复制选中文本到划词AI释义」作为备用入口。

## 安装（加载已解压的扩展）

1. 打开浏览器，进入 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录：`C:\Users\Chinasoft\Documents\GitHub\AI_explain`。
4. 点击工具栏插件图标（或右上角扩展）进入设置。

## 使用

1. 打开设置页，选择服务商并填写 **API Key**（可选调整模型、地址、温度、系统提示词）。
2. 点「保存设置」，可点「测试连接」验证。
3. 打开任意网页，选中一段文字，浮层自动出现并给出解释。

## 目录结构

```
manifest.json      # MV3 清单（权限、后台、内容脚本、图标）
background.js      # Service Worker：统一代理所有 AI API 请求（流式/非流式）
content.js         # 内容脚本：选择检测 → 浮层 → 流式渲染
content.css        # 浮层样式（毛玻璃卡片）
options.html/js    # 设置页：服务商/Key/模型/提示词/行为开关
icon*.png          # 扩展图标
```

## API 说明

- 默认按 OpenAI 兼容协议调用：`POST {baseUrl}/chat/completions`，`Authorization: Bearer <key>`。
- 豆包（火山方舟 Ark）：Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`，**模型名需填你在方舟上创建的「推理接入点」**（形如 `doubao-1-5-vision-pro-32k-250828` 或自定义 `ep-xxxx`）。
- Key 仅保存在本地浏览器（`chrome.storage.local`），由后台 Service Worker 使用，不会注入页面。

## 默认系统提示词（可在设置页改）

默认风格会兼顾：外文翻译 + 专业术语通俗讲解 + 文言文与汉字的本字、造字原意与字形演变考证 + 要点式简洁回答；并**强制 AI 按「分板块标题 + 逐词无序列表」的规范格式输出**，禁止把小节标题或整句翻译并进逐词解释行，从而避免排版错乱。若改过提示词导致排版乱，可在设置页点「恢复默认提示词」一键还原。

## 说明与限制

- 未配置 API Key 时浮层会提示前往设置。
- 选中文字默认截断为 500 字（设置页可改），避免无谓消耗。
- 无法在本机离线验证真实 API 调用，需在浏览器加载并配置 Key 后实测。
