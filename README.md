# 划词AI释义（AI_explain）

一个浏览器扩展（Chrome / Edge，Manifest V3）：**选中网页上的文本 → 自动弹出浮层 → 调用你配置的大模型 API → 对所选文本进行释义、翻译或讲解**。风格类似「划词翻译」，但由 AI 自由解释，而非仅翻译。

## 核心功能

- 选中文本后自动弹出浮层，默认自动调用 AI 解释（也可改为手动点「解释」）。
- **点击工具栏插件图标即可暂停/恢复划词**：暂停时图标变为暂停符号，选中文字不再弹浮层；设置页里也有同名开关。
- 释义采用**流式输出**（逐字显示）；支持复制释义、一键跳转到历史、设置。
- **多提示词**：可存多份提示词（默认内置「默认释义 / 简洁速览 / 翻译优先」三份），在设置页新增、复制、改名、删除；浮层里原文行最右侧有下拉（无标签，悬停提示「切换AI提示词」），切换后立即生效、记住选择，并用新提示词重新解释当前这段文字。
- 发送时带上选中文本所在的**页面上下文**（前后各一段文字），让 AI 更准确理解语境。
- 浮层可拖动标题栏移动位置、用右下角、下边、右边手柄拉宽拉高，尺寸与位置自动记忆。
- **摘录模式**：右键点击工具栏插件图标，在菜单项中开启（图标左上角出现粉点），此时划词不调用 AI，只把选中文本收入历史，适合只收集语料、不想花 token 的场景。
- **高亮模式（高亮划词）**：在插件图标右键菜单开启后，划词与摘录的文字会用荧光笔在文字下半部分划线（8 种常用荧光色 + 调色盘自选），划线按页面地址保存、刷新后自动恢复；鼠标悬停划线可直接复读该处的历史释义，不调用 AI、不重复计费。
- **历史记忆**：每次释义成功后自动写入历史记录（可在设置页关闭），浮层点「历史」可查看、搜索、删除，并可导出为 **Markdown** 或 **HTML**（按原文卡片样式，可打印或用浏览器打印功能保存为 PDF），可选时间/来源/页面地址等字段，也可导出 JSON 格式的备份数据用于备份或数据迁移，或在不同设备间同步数据（导入支持覆盖或合并模式）。
- **设置同步（可选，`chrome.storage.sync`）**：接口地址、模型、API Key、多份提示词、摘录/高亮开关等设置走浏览器账号，在本账号的多台电脑间自动同步；「暂停」状态与历史记录不同步（历史用下面的 WebDAV）。
- **跨设备同步（可选，WebDAV）**：在设置页第④卡填入自己的 WebDAV（如坚果云）地址、账号与应用密码，多台电脑填同一路径即可共用一份历史，含摘录与高亮同步所需的原文；合并按 `id` 去重、同一条取时间较新的，删除会留墓碑，不会在另一台机器上被重新拉回来。
- 内置 DeepSeek / 豆包(火山方舟) / OpenAI / Kimi 常用配置，也支持任意 OpenAI 兼容接口。

## 安装（加载已解压的扩展）

1. 打开浏览器，进入 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本插件下载到的目录。
4. 右键点击工具栏插件图标，选「选项」进入设置页（左键单击图标是暂停/恢复划词）。

## 使用

1. 打开设置页，选择服务商并填写 **API Key**（可选调整模型、地址、温度、系统提示词）。
2. 点「保存设置」，可点「测试连接」验证。
3. 打开任意网页，选中一段文字，浮层自动出现并给出解释。
4. 释义成功后自动存入历史记录；点浮层右上角「历史」可查看/搜索/删除，并点「导出为 MD」下载 Markdown 文件。记录保存在本地浏览器，默认最多保留 1000 条（可在设置页调整），超出自动覆盖最早的记录；接近上限时浮层标题会提示去导出备份。多台电脑要共用一份历史，见下方「跨设备共享历史」。

## 目录结构

```
manifest.json      # MV3 清单（权限、后台、内容脚本、图标）
background.js      # Service Worker：统一代理所有 AI API 请求（流式/非流式）
content.js         # 内容脚本：选择检测 → 浮层 → 流式渲染
content.css        # 浮层样式（毛玻璃卡片）
options.html/js    # 设置页：服务商/Key/模型/提示词/行为开关
history.html/js    # 历史记录页：查看/搜索/聚合/删除/导入导出（MD、HTML、JSON）
icon*.png          # 扩展图标
```

## API 说明

- 默认按 OpenAI 兼容协议调用：`POST {baseUrl}/chat/completions`，`Authorization: Bearer <key>`。
- 豆包（火山方舟 Ark）：Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`，**模型名需填你在方舟上创建的「推理接入点」**（形如 `doubao-1-5-vision-pro-32k-250828` 或自定义 `ep-xxxx`）。
- Key 仅保存在本地浏览器（`chrome.storage.local`），由后台 Service Worker 使用，不会注入页面。

## 提示词（可在设置页改，也可存多份）

默认风格会兼顾：外文翻译 + 专业术语通俗讲解 + 文言文与汉字的本字、造字原意与字形演变考证 + 要点式简洁回答；并**强制 AI 按「分板块标题 + 逐词无序列表」的规范格式输出**，禁止把小节标题或整句翻译并进逐词解释行，从而避免排版错乱。若改过提示词导致排版乱，可在设置页点「恢复默认提示词」一键还原。

除这份默认外，还内置「简洁速览」（三句话讲清大意）与「翻译优先」（先整段译文，再注释不超过 3 个难点词）。三份都可在设置页改名、改正文、复制或删除，也能在浮层下拉里切换。

## 设置同步（浏览器账号）

设置页第⑤卡「设置同步（浏览器账号）」，用 `chrome.storage.sync`：

- 同步内容：`config`（接口地址、模型、温度、字数上限、API Key、多份提示词与当前选中项、荧光笔颜色、WebDAV 账号等）+ 摘录模式 / 高亮划词两个开关。
- 不同步：**暂停状态**（属单机行为，同步会把另一台也停掉）与**历史记录**（改用上面的 WebDAV）。
- 触发时机：设置改动后约 1.5 秒自动推送；另一台电脑开着浏览器时通过 `storage.onChanged` 实时收；浏览器启动和新装/更新扩展时拉取一次。远端 `config` 按字段浅合并到本地，本地独有的字段保留。
- 关掉这个开关后，本机不再推送也不再拉取（已同步的数据留在账号里）。
- 配额：`chrome.storage.sync` 单账号 100KB、单项 8KB；本插件只存一份 `config` 加两个开关，远低于限制；将来若设置项明显膨胀（如超大提示词），需拆分存储。

## 跨设备共享历史（WebDAV / 坚果云）

设置页第④卡「云端同步（WebDAV）」：

1. 坚果云网页端「账户信息 → 安全选项 → 添加应用密码」，拿到一串**应用密码**（不是登录密码）。
2. 勾选「启用云端同步」，地址填 `https://dav.jianguoyun.com/dav/`，账号填坚果云注册邮箱，密码填应用密码。
3. 远端文件路径默认 `AI_explain/history.json`（目录不存在会自动创建），多台电脑填**同一账号 + 同一路径**。
4. 先点「测试连接」确认账号可用，再点「立即同步」；「历史变动后自动同步」开着时，划词、删除、清空、导入后延迟约 4 秒自动合并一次。

合并规则：

- 按 `id` 求并集，同一条记录取 `time` 更大（更新）的那份；
- 删除 / 清空会写**墓碑**（保留 90 天、最多 2000 条），墓碑里的 id 在两端都直接剔除，所以一端删掉的记录不会被另一端重新推回来；
- 合并后仍按「历史上限」裁剪；导出 JSON 备份里**不含** WebDAV 账号与密码。

## 说明与限制

- 未配置 API Key 时浮层会提示前往设置。
- 选中文字默认截断为 500 字（设置页可改），避免无谓消耗。
- 无法在本机离线验证真实 API 调用，需在浏览器加载并配置 Key 后实测。
