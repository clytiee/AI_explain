选择网页文本后自动弹出浮层，调用你配置的大模型 API 对所选文本进行释义。

① API 服务

Key 仅保存在本地浏览器（chrome.storage.local），由后台 Service Worker 使用，不会注入到页面。

② 释义偏好

选中后自动调用 AI 解释
关闭后仅弹出浮层，点击「解释」按钮才发起请求，节省额度。
自动保存释义到历史记录
释义成功后写入历史，可在浮层点「历史」查看并导出为 Markdown。
记录保存在本地浏览器。条数越大占用的本地存储越多。

流式输出（逐字显示）
关闭则等待完整结果一次性返回。
下拉里选中的就是当前用于释义的那份；改名、改正文后点「保存设置」生效。网页浮层里也能直接切换，改选后立即生效，并用新的提示词重新解释当前这段文字。默认风格会兼顾外文翻译、专业术语通俗讲解、文言文与汉字的本字及造字原意考证，并强制 AI 按「分板块 + 逐词列表」的规范格式输出，避免把整句翻译并进逐词解释里。

③ 高亮划词

高亮划词
全新安装时默认开启。开启后，网页上的划词与摘录会用荧光笔在文字下半部分划线标记，划线按页面保存，刷新后自动恢复；也可右键点击工具栏图标，用「高亮划词」菜单随时开关。关闭时会清除本页已划的线及其保存记录。
调色盘： #fef08a
点击常用色快速选择，或用调色盘自定义。点「保存设置」后生效，页面上已划线的文字会同步更新颜色。

④ 云端同步（WebDAV）

启用云端同步
把历史记录同步到你自己的 WebDAV（坚果云等），多台电脑填同一账号与路径即可共用一份历史。云端文件只放原文与释义，不含 API Key。
历史变动后自动同步
划词、删除、清空后延迟约 4 秒合并一次；关闭则只在你点「立即同步」时上传。
坚果云：网页端「账户信息 → 安全选项 → 添加应用密码」，地址填 https://dav.jianguoyun.com/dav/。多台电脑填同一账号与路径；合并按 id 去重、同一条取时间较新的，删除会留墓碑，不会在另一台机器上被重新拉回来。

⑤ 设置同步（浏览器账号）

在本账号的其他电脑同步设置
用 chrome.storage.sync 走浏览器账号，同步接口地址、模型、API Key、多份提示词、摘录/高亮开关等设置项；「暂停」状态与历史记录不在此列（历史用上面的 WebDAV）。改动后约 1.5 秒自动推送，其他电脑打开浏览器时自动拉取。

⑥ 来源标题替换

按网址前缀匹配来源（例如 https://www.zhihu.com/），命中后把来源名称里的指定文本替换掉。只改显示与导出的文字，不改记录本身，也不改链接地址；「查找」留空表示整条标题替换成「替换为」。多条规则按顺序依次生效，保存设置后生效。

使用步骤：① 填写 API Key 并保存 → ② 打开任意网页选中一段文字 → ③ 浮层自动弹出并解释。 尚未安装？在 Chrome / Edge 的 chrome://extensions 打开「开发者模式」→「加载已解压的扩展程序」，选择本目录即可。
