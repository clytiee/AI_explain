## 修复：悬停逻辑劫持划词浮层
- 根因：openPopup→applyHighlight 把选区包进 .aie-hl 时 DOM 替换使浏览器对新 span 触发 mouseover（mouseup 已发生、mouseDown=false），150ms 后 showHoverPopup 劫持刚打开的释义浮层。连锁：显示「未找到历史释义」覆盖释义、savedThisExplain 被置 true 导致历史不写入、hover-hide 的 hidePopup disconnect 掐断 AI 流、历史缺失导致刷新恢复少一路来源。
- 修复：showHoverPopup 开头加 guard `if (!hoverPopup && isVisible()) return;`（普通划词浮层显示中不劫持）+ abortPort() 停掉旧流。注意：钉住的普通浮层显示期间悬停不生效（先关浮层再悬停）。

## 高亮划词功能
- 图标右键菜单新增「高亮划词」开关（background.js：ai-explain-highlight 菜单项，storage key `highlightMode`，菜单标题随状态切换）。
- content.js：开启时，划词/摘录的选区用 `range.extractContents()` 包裹进 `<span class="aie-hl">`，CSS 渐变在文字下半部分画荧光笔线（`--aie-hl` 变量控制颜色，`box-decoration-break: clone` 保证跨行每行都有线）。包裹后 range 失效，置 `currentRange = null` 停止滚动跟随；上下文改由 openPopup 提前取出存 `lastContext`。
- 关闭开关自动清除本页所有划线（clearHighlights，unwrap + normalize）；改颜色会同步已有划线（syncHighlightColors）。
- 修复：开启「高亮划词」时立即补划页面上已有选区（highlightExistingSelection），此前只在浮层弹出时才划线，已选好的文字不会被打标。
- 划线持久化：按页面 URL（origin+path+search）存 `chrome.storage.local.highlights`（{t, items:[{text}]}，每页≤500条、保留最近200页）；刷新后 restoreHighlights 用 TreeWalker 累积正文文本（跳过 script/style/浮层/.aie-hl）检索原文，wrapFirstMatch 从文档末尾往前分片段重新包裹。颜色取当前 config.highlightColor（改色全局同步）。关闭开关时清除本页 DOM 划线并删除存储记录。限制：SPA 路由变化/动态加载内容不会自动重扫。
- options：新增「③ 高亮划词」卡片——开关即时生效；8 个常用荧光笔色块 + 调色盘（input type=color），颜色存 config.highlightColor，随「保存设置」持久化。
- 历史记录回溯：background 新增 `highlight-history` 消息，按 pageUrl（origin+path+search）筛出本页历史划词/摘录原文（去重、最多200条），content 恢复高亮时一并补划——以前的划词与摘录记录同样显示荧光笔。注意：历史里超长选区保存时被 maxLength 截断过，截断原文匹配不到会静默跳过。
- 悬停读历史释义：高亮模式下鼠标悬停划线（.aie-hl，150ms 防抖、按下拖选时不触发）→ `highlight-lookup` 消息取同页面同原文的最新历史条目 → 弹浮层直接渲染 entry.answer（renderMarkdown），不调 AI、不写历史（savedThisExplain=true）。有 answer 显示「历史释义（悬停）」，无 answer 显示「摘录 · 该划词未释义」，查不到显示提示。移出划线 250ms 后自动关浮层，移入浮层取消关闭；普通划词 openPopup 会接管（hoverPopup=false）。
- 钉住浮层：浮层标题栏 × 前加钉住按钮（.aie-pin，用户提供 Downloads/pin.svg 的斜置线性图钉，内联 SVG + currentColor：默认灰、钉住后靛蓝底），点击切换 pinned；钉住后点击页面空白、悬停移开都不自动关（mouseup 与悬停 250ms 定时关闭均检查 !pinned），Esc/×/暂停仍可关。新划词/新悬停弹层默认取消钉住（setPinned(false)），hidePopup 复位。
