## 跨设备共享历史：坚果云 WebDAV（选定方案）
- 方案比较：`chrome.storage.sync` 只有 100KB/8KB 单项，装不下历史；自建后端（已有 Django 站）能多用户＋网页端检索但要维护服务与鉴权；最终用户拍板 **WebDAV（坚果云）**，零后端、扩展的 `host_permissions: <all_urls>` 已覆盖跨域。
- `background.js`：`DEFAULT_SYNC`（`url` 默认 `https://dav.jianguoyun.com/dav/`、`file` 默认 `AI_explain/history.json`、`auto:true`、`enabled:false`）。同步引擎：`b64utf8`（UTF-8 安全 Basic 认证）、`davUrl`（逐段 encodeURIComponent）、`ensureDavDir`（逐级 MKCOL，405 视为已存在）、`readRemote`（404/空文件视为 missing）、`writeRemote`（PUT）、`mergeRecords`（id 并集 + 同 id 取 time 大者 + 墓碑剔除）、`runSync`（`syncing` 单飞 + 静默失败留 `syncState`）、`scheduleSync`（4 秒去抖，仅 enabled&&auto）。
- 删除不复活：新增 `syncTombstones`（`{id,time}`，TTL 90 天、上限 2000）；`deleteHistory`/`clearHistory` 先写墓碑再排同步；`saveHistory` 也排同步。
- 消息接口新增 `sync-now`（手动合并上传）、`sync-test`（只读远端不上传）、`history-changed`（历史页导入等直改存储的路径通知后台排同步）；`chrome.runtime.onStartup` 延迟 1.5s 补一次。

## 设置同步（chrome.storage.sync）
- 需求：「把选项、开关等也同步」，走浏览器账号，不占用 WebDAV。
- `manifest.json` **不要**加 `sync` 权限（Chrome 无此权限名，加载会报 "Permission 'sync' is unknown."）；`chrome.storage.sync` 只用 `storage` 权限即可。
- `background.js`：`SETTINGS_SYNC_KEY = "settingsSync"`（本机开关，默认开，**本身不进 sync**，避免一端关掉把另一端也关）；`SETTINGS_SYNC_FIELDS = ["config","highlightMode","extractMode"]`。
- 推送：本地 `storage.onChanged` 里 config / extractMode / highlightMode 变动 → 1.5 秒去抖后写 `chrome.storage.sync`；`applyingRemoteSettings` 标记 + 600ms 窗口防止「拉下来又推回去」的乒乓。
- 拉取：`storage.onChanged(area==="sync")` 实时接收；`onStartup` 800ms、`onInstalled` 各拉一次。远端 config 与本地 **按字段浅合并**（保留本地独有字段），开关直接覆盖。
- 不同步：`paused`（单机行为，同步会把另一台也停掉）、历史记录（继续用 WebDAV）。
- `options.html/js`：第⑤卡「设置同步（浏览器账号）」单开关 `settingsSync`，改动立即落盘；`load()` 里 `settingsSync` 默认 true。
- README 加「设置同步（浏览器账号）」章节（同步范围、触发时机、配额 100KB/8KB）。

## 修：设置没同步到另一台（WebDAV 账号、应用密码）
- 现象：A 机存好坚果云账号/应用密码，B 机设置页里还是空。
- 原因：`chrome.storage.sync` 的 `onChanged` **不会唤醒休眠的 Service Worker**，原实现只在 `onStartup` / `onInstalled` 拉取；B 机浏览器一直开着、worker 早睡了，就永远收不到。
- 改法：① `background.js` 末尾无条件 `pullSettingsFromSync()`，worker 每次被唤醒都补拉一次；② 新增 `settings-pull` 消息，设置页 `DOMContentLoaded` 先请后台拉一次再回填表单（2 秒兜底调用 `load()`）。README 的触发时机同步改写。
