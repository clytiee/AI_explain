划词AI释义 · 设置

选择网页文本后自动弹出浮层，调用你配置的大模型 API 对所选文本进行释义。

① API 服务

Key 仅保存在本地浏览器（chrome.storage.local），由后台 Service Worker 使用，不会注入到页面。

② 释义偏好

暂停划词（点击工具栏图标亦可切换）
暂停后选中文字不再弹出浮层，图标会变为带红斜杠。
选中后自动调用 AI 解释
关闭后仅弹出浮层，点击「解释」按钮才发起请求，节省额度。
流式输出（逐字显示）
关闭则等待完整结果一次性返回。
默认风格会兼顾外文翻译、专业术语通俗讲解、文言文与汉字的本字及造字原意考证，并强制 AI 按「分板块 + 逐词列表」的规范格式输出，避免把整句翻译并进逐词解释里。改过提示词导致排版乱时，可一键恢复。

使用步骤：① 填写 API Key 并保存 → ② 打开任意网页选中一段文字 → ③ 浮层自动弹出并解释。 尚未安装？在 Chrome / Edge 的 chrome://extensions 打开「开发者模式」→「加载已解压的扩展程序」，选择本目录即可。
